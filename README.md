# HSK 1–9 แฟลชการ์ด — ชุดไฟล์สำหรับขึ้น Google Play

ไฟล์ในโฟลเดอร์นี้

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | ตัวแอปทั้งหมด (คำศัพท์ 11,000 คำอยู่ในไฟล์นี้) |
| `manifest.webmanifest` | ข้อมูลแอป: ชื่อ ไอคอน สี ให้ติดตั้งเป็นแอปได้ |
| `sw.js` | Service worker ให้แอปเปิดได้แม้ไม่มีอินเทอร์เน็ต |
| `privacy.html` | นโยบายความเป็นส่วนตัว (Google Play บังคับต้องมี) |
| `icons/` | ไอคอนแอป 192, 512 และแบบ maskable |
| `.nojekyll` | บอก GitHub Pages ไม่ให้ซ่อนโฟลเดอร์ `.well-known` (ห้ามลบ) |

## ก่อนอัปโหลด ต้องแก้ 2 จุดใน `privacy.html`

1. `[วันที่เผยแพร่]` → ใส่วันที่
2. `[อีเมลของคุณ]` และ `[your email]` → ใส่อีเมลที่ใช้ติดต่อ

## ขั้นต่อไป

ขั้นที่ 2: อัปโหลดทั้งโฟลเดอร์นี้ขึ้น GitHub Pages
ขั้นที่ 3: ใช้ PWABuilder.com สร้างไฟล์ `.aab` แล้วนำไฟล์ `assetlinks.json` ที่ได้มาใส่ในโฟลเดอร์ `.well-known/`

## ถ้าแก้ไขแอปภายหลัง

เปลี่ยน `VERSION` ในไฟล์ `sw.js` (เช่น `hsk-v1` → `hsk-v2`) ทุกครั้งที่อัปโหลดเวอร์ชันใหม่ เพื่อให้เครื่องผู้ใช้โหลดของใหม่
